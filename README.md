# Proyecto Grafo en Java

## Descripción

Este proyecto implementa estructuras de datos basadas en **nodos personalizados**, permitiendo la creación y manipulación de grafos en Java.

Se desarrolló como parte del aprendizaje de:

* Estructuras de datos
* Manejo de nodos
* Listas enlazadas
* Lógica de grafos
  
## Funcionalidades

* Creación de nodos personalizados
* Conexión entre nodos
* Recorrido de estructuras
* Representación básica de grafos

## Estructura del proyecto

```bash
src/
 └── modelo/
     ├── TNodo.java
     ├── TLista.java
     └── TGrafo.java

## Cómo ejecutar

1. Compilar:

```bash
javac src/**/*.java
```

2. Ejecutar:

```bash
java main.Main
```

* Manipulación de referencias en memoria
* Separación por capas (modelo/vista)
* Organización de proyectos en Java
